# Asset Library — Product Decisions Log

Asset Library by Saxenas Creation. Each entry records what was decided, why, and when.
Status: **Phase 0 — Product discovery** (in progress).

## Founder guidance (applies to all decisions)

- **Ship fast.** Avoid long feedback/iteration loops. Sensible defaults are made by the team and
  only escalates decisions that are genuinely the founder's call.
- Users must be able to install by double-clicking: **`.dmg` (macOS) and `.exe` (Windows)**.

## Batch D — Distribution & licensing (2026-10-11)

| #   | Decision                                                                                                             | Consequence                                                                                                                                                                                                                                                                  |

## Batch F — Product goal and panel architecture (2026-10-12)

| #   | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| F1  | **North star: a free alternative to Premiere Composer.** Assets work natively inside Premiere Pro (and later After Effects): browse and preview in a panel, then put them straight on the timeline.                                                                                                                                                                                                                                                                                                         |
| F2  | **The Premiere Pro panel is the primary product.** The desktop app is the engine behind it (indexing, SQLite, FFmpeg previews) and stays useful on its own (drag-out works with any editor).                                                                                                                                                                                                                                                                                                                |
| F3  | **Panel ↔ engine contract = files on disk, not a network link.** The engine writes a read-only catalog (`catalog.json`, written atomically) plus thumbnails, preview MP4s, hover-scrub sprites and waveforms into the app's data folder. The UXP panel reads them with `localFileSystem: "fullAccess"`. Reason: localhost permissions in installed UXP plugins are unreliable in Premiere 26.x, the Marketplace forbids launching external apps, and hybrid (native) plugins would need Apple notarization. |
| F4  | **Insert from the panel:** read the playhead (`Sequence.getPlayerPosition`), `Project.importFiles` the original into an "Asset Library" bin (reuse if already imported), then an overwrite or insert action on a track chosen in the panel (Premiere has no "targeted track" API). Originals go in as-is, so ProRes 4444 alpha keeps its alpha.                                                                                                                                                             |
| F5  | **Drag from the panel onto the timeline** is enabled only on Premiere **27.0+** (Adobe's requirement, currently beta). On 26.x the panel uses double-click and an "Insert at playhead" button; the desktop app's drag-out remains available.                                                                                                                                                                                                                                                                |
| F6  | **Panel UI:** plain UXP HTML/CSS with our own theme (no CSS Grid in UXP, so flexbox + a virtualized list); React is used only if it renders reliably in Premiere's UXP.                                                                                                                                                                                                                                                                                                                                     |
| F7  | **Distribution:** the `.dmg`/`.exe` installs the desktop engine and installs the panel's `.ccx` through Adobe's UPIA command-line tool. No hybrid plugin.                                                                                                                                                                                                                                                                                                                                                   |
| F8  | Never interfere with the founder's running Premiere/After Effects sessions. Host tests are done by the founder, or only with their go-ahead.                                                                                                                                                                                                                                                                                                                                                                |

## Defaults (minor, reversible)

- **UI font:** Geist (OFL), bundled locally. **Icons:** lucide-react (ISC).
- **App data / IDs:** appId `com.saxenascreation.assetlibrary`; repo name `saxenaxoxo/asset-library` (not created yet).
- **Platform targets:** macOS Apple Silicon + Intel, Windows x64. Windows ARM later.
- **Stack (from research):** Electron 44, electron-vite 5, electron-builder 26, better-sqlite3 13 (FTS5),
  LGPL FFmpeg spawned from a utility process, wavesurfer.js for waveforms.
