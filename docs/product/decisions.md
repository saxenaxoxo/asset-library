# Asset Library — Product Decisions Log

Asset Library by Saxenas Creation. Each entry records what was decided, why, and when.
Status: **Phase 0 — Product discovery** (in progress).

## Founder guidance (applies to all decisions)

- **Ship fast.** Avoid long feedback/iteration loops. Sensible defaults are made by the team and
  only escalates decisions that are genuinely the founder's call.
- Users must be able to install by double-clicking: **`.dmg` (macOS) and `.exe` (Windows)**.

## Batch F — Product goal and panel architecture (2026-10-12)

| #   | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| F1  | **North star: a free alternative to Premiere Composer.** Assets work natively inside Premiere Pro (and later After Effects): browse and preview in a panel, then put them straight on the timeline.                                                                                                                                                                                                                                                                                                         |
| F2  | **The Premiere Pro panel is the primary product.** The desktop app is the engine behind it (indexing, SQLite, FFmpeg previews) and stays useful on its own (drag-out works with any editor).                                                                                                                                                                                                                                                                                                                |
| F3  | **Panel ↔ engine contract = files on disk, not a network link.** The engine writes a read-only catalog (`catalog.json`, written atomically) plus thumbnails, preview MP4s, hover-scrub sprites and waveforms into the app's data folder. The UXP panel reads them with `localFileSystem: "fullAccess"`. Reason: localhost permissions in installed UXP plugins are unreliable in Premiere 26.x, the Marketplace forbids launching external apps, and hybrid (native) plugins would need Apple notarization. |
| F4  | **Insert from the panel:** read the playhead (`Sequence.getPlayerPosition`), `Project.importFiles` the original into an "Asset Library" bin (reuse if already imported), then an overwrite or insert action on a track chosen in the panel (Premiere has no "targeted track" API). Originals go in as-is, so ProRes 4444 alpha keeps its alpha.                                                                                                                                                             |
| F5  | **Drag from the panel onto the timeline** is enabled only on Premiere **27.0+** (Adobe's requirement, currently beta). On 26.x the panel uses double-click and an "Insert at playhead" button; the desktop app's drag-out remains available.                                                                                                                                                                                                                                                                |
| F6  | **Panel UI:** plain UXP HTML/CSS with our own theme (no CSS Grid in UXP, so flexbox + a virtualized list); React is used only if it renders reliably in Premiere's UXP.                                                                                                                                                                                                                                                                                                                                     |
| F7  | **Distribution:** the `.dmg`/`.exe` installs the desktop engine and installs the panel's `.ccx` through Adobe's UPIA command-line tool. No hybrid plugin.                                                                                                                                                                                                                                                                                                                                                   |
| F9  | **After Effects now: "Send to After Effects" from the desktop app** (ExtendScript run in the already-open AE via AppleScript `DoScriptFile` on macOS / `AfterFX.exe -r` on Windows). Imports originals, optionally adds a layer at the comp's current time, applies `.ffx` to selected layers, imports `.aep` as a project; one undo step; never launches AE. A native AE panel follows when AE's UXP support ships (27.0, beta).                                                                           |
| F8  | Never interfere with the founder's running Premiere/After Effects sessions. Host tests are done by the founder, or only with their go-ahead.                                                                                                                                                                                                                                                                                                                                                                |

## Batch G — The panel is the app (2026-10-12, after testing in Premiere)

| #   | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| G1  | **Everything happens in the Premiere panel**: browse, preview, favorites, tags, add folders, import, settings. The desktop app becomes a **background engine** (starts at login, menu-bar/tray icon, no window needed) that indexes, makes thumbnails with FFmpeg and carries out the panel's requests. Supersedes the "useful on its own" half of F2; its window stays available from the tray.                                                   |
| G2  | **Panel → engine requests are files** in `<catalog>/requests/`, answered in `<catalog>/engine.json` (status, settings, results by request id). Same reasons as F3. The panel starts the engine through the `assetlibrary://` URL scheme when it isn't running. Contract: `packages/catalog/requests.ts`.                                                                                                                                           |
| G3  | **Folders view is the default**, modelled on Premiere Composer / Animation Composer so people can switch easily: folder tree (All assets, Favorites, library folders, tags) beside the thumbnail grid, breadcrumb and Import in a toolbar. The flat grid stays as the "All" view.                                                                                                                                                                  |
| G4  | **Import = add files to the library** (Premiere Composer's meaning): the chosen files are **copied** into the folder selected in the tree, or into an "Asset Library Imports" folder. Never overwrites (a copy becomes "name 2.ext") and never moves or deletes the originals. This is the one place the app writes into library folders, and only on the editor's explicit request. "+ Add folder" indexes a folder where it is, with no copying. |
| G5  | **No selection preview in the footer**: the selected tile's highlight is the selection. Video playback isn't possible inside Premiere's panel runtime (`<video>.play()` fails in the host), so previews are images and hover-scrub.                                                                                                                                                                                                                |
| G6  | **Send to After Effects uses AE's raw `DoScriptFile` event code**, because the named command fails (-1708) when the AE version is chosen at run time.                                                                                                                                                                                                                                                                                              |

## Batch H — Scale and the Premiere runtime (2026-10-12, late)

| #   | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| H1  | **Nothing in view is ever rebuilt by a routine render.** Premiere's panel runtime reports a window resize for the panel's own layout work, so a render loop is one careless handler away, and an element replaced between two renders never receives a click. Tiles, tree rows and the Settings tab are keyed and updated in place; styles are written only when they change; a resize that doesn't change the panel's size is ignored.                                                                                                                          |
| H2  | **Small library changes reach the panel as a delta.** The engine writes a full `catalog.json` (new generation) at startup, when a change touches more than 2,000 assets or 15 % of the library, when the folder list changes at all, or when the delta is over ten minutes old; otherwise it rewrites a cumulative `catalog-delta.json`. The panel applies the delta to the catalog it already has, so a 100k-asset library never re-parses 60 MB for a favorite.                                                                                                |
| H3  | **Several assets at once.** Shift and Cmd/Ctrl select in the grid; Enter or "Add N at playhead" places them one after another, moving the playhead by each clip's length. Sound is auditioned by the engine (a hidden player), since a panel can't play media. "Recent" lists what was placed last.                                                                                                                                                                                                                                                              |
| H4  | **The panel ships as a CEP extension for Premiere Pro 24–26, and as a UXP plugin from Premiere 27.** Dragging from a panel onto the timeline is the feature editors expect most, and Premiere only reads drags from UXP panels from version 27 (still the beta); CEP panels can hand Premiere file paths today (`com.adobe.cep.dnd.file.<n>`, the channel Premiere Composer uses). One codebase: the UI is shared, the host layer (`src/host-cep`, `src/host-uxp`) is chosen at build time. Supersedes the "UXP only" reading of G1; the panel is still the app. |

## Defaults (minor, reversible)

- **UI font:** Geist (OFL), bundled locally. **Icons:** lucide-react (ISC).
- **App data / IDs:** appId `com.saxenascreation.assetlibrary`; repo name `saxenaxoxo/asset-library` (not created yet).
- **Platform targets:** macOS Apple Silicon + Intel, Windows x64. Windows ARM later.
- **Stack (from research):** Electron 44, electron-vite 5, electron-builder 26, better-sqlite3 13 (FTS5),
  LGPL FFmpeg spawned from a utility process, wavesurfer.js for waveforms.
